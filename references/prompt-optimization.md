# 3D 提示词优化方案

## 目标

`3D` 是一个上位风格，不默认把用户锁定到卡通或写实。用户只输入 `3D` 时，模型可以自由选择一种统一的 3D 动画风或 3D 真实人物风格；用户明确写出子风格时，子风格升级为硬约束。

## 编译规则

1. 先判断用户是否只说了 `3D`，还是明确写出了 `3D 卡通/动画`、`3D 写实/真人` 等子风格。
2. 只有明确的子风格才加入对应的禁止项：动画风禁止照片剪纸和真人摄影质感；真实人物风禁止 Q 版、夸张头身比和卡通塑料质感。
3. 未指定子风格时，提示词只要求“选择一种并保持全图一致”，不把任一分支伪装成默认限制。
4. 风格优先级高于泛化的“表情包/公众人物”视觉先验；身份锁定单独描述，避免模型为了辨识人物退回照片剪纸。
5. 表情按输入顺序映射到 `columns × rows` 的行优先格子；每格一个反应，装饰只服务于该反应，不跨格。
6. 白边是独立的呈现参数，不是 3D 风格本身：默认关闭；用户选择 `white` 或明确写出“白边贴纸风”时开启，并要求窄、均匀、连续、只包围本格主体。

## 生成提示词骨架

```text
风格优先级：<自由选择一种 3D 处理 / 用户明确指定的硬约束>
身份锁定：<脸部、发型、比例、服装、配饰、颜色>
构图：<columns × rows>，按行优先逐格对应表情
动作语义：每格一个明确反应，保留安全留白
技术约束：真实 alpha、透明格间、无跨格内容
```

白边参数可通过 CLI 的 `--sticker-outline white` 开启；`auto` 会从“3D 卡通白边贴纸”等自然输入中识别，`none` 可强制关闭。该规则由 `scripts/compile_static_prompt.py` 执行，风格别名维护在 `references/style-presets.json`。
